## 3. TIPOGRAFÍA

### Fuentes Recomendadas

**Títulos (H1, H2, H3):**
- Familia: Poppins o Montserrat
- Peso: Bold (700)
- Ejemplo: "Bienvenido a Acrilinco"

**Cuerpo de texto (párrafos):**
- Familia: Segoe UI, Open Sans
- Peso: Regular (400)
- Ejemplo: "Descripciones de productos"

**Monoespaciada (código):**
- Familia: Courier New, Consolas
- Peso: Regular (400)

### Jerarquía de Tamaños

| Elemento | Tamaño | Peso |
|----------|--------|------|
| H1 | 3rem (48px) | Bold 700 |
| H2 | 2.5rem (40px) | Bold 700 |
| H3 | 2rem (32px) | Bold 700 |
| H4 | 1.5rem (24px) | Bold 700 |
| Párrafo | 1rem (16px) | Regular 400 |
| Pequeño | 0.875rem (14px) | Regular 400 |

## 4. COMPONENTES

### Botones

**Botón Primario (Acción principal)**
- Fondo: Naranja (#fd5017)
- Texto: Blanco
- Padding: 0.75rem 2rem
- Border-radius: 5px
- Hover: Fondo más oscuro

**Botón Secundario (Acción secundaria)**
- Fondo: Azul Oscuro (#033380)
- Texto: Blanco
- Padding: 0.75rem 2rem
- Border-radius: 5px
- Hover: Fondo más oscuro

**Botón Éxito (Confirmación)**
- Fondo: Verde (#27AE60)
- Texto: Blanco
- Padding: 0.75rem 2rem
- Border-radius: 5px

**Botón Error (Peligro)**
- Fondo: Rojo (#E74C3C)
- Texto: Blanco
- Padding: 0.75rem 2rem
- Border-radius: 5px

### Tarjetas (Cards)

- Fondo: Blanco (#FFFFFF)
- Sombra: 0 4px 6px rgba(0,0,0,0.1)
- Border-radius: 10px
- Padding: 1.5rem a 2rem
- Hover: Elevar con box-shadow más fuerte

### Inputs / Formularios

- Borde: 1px solid #BDC3C7
- Fondo: Blanco
- Padding: 0.75rem
- Border-radius: 5px
- Focus: Borde #033380 con sombra azul suave

## 6. SOMBRAS


**Sombra Fuerte (modals):**
